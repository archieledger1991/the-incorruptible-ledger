🕸️ 5. SECURITY AND INDESTRUCTIBILITY

Because the system presents the state's own data back to the public, it is legally insulated from standard censorship mechanisms. However, to defend against aggressive technical or legal shutdown attempts, it uses a decentralized survival strategy:
• No Central Server: The tool does not live on a single computer. Its code and databases are shared globally across users using decentralized file networks. If a domain name is blocked or seized by a court, the system regenerates on a new node immediately.
• Offline Execution: Because the engine relies on compact, open-source AI models running locally, any individual can download the entire tool onto a basic home laptop and run the auditor completely hidden from corporate surveillance.
